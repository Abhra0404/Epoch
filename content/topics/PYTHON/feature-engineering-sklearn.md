## 1. CORE CONCEPT

**Feature Engineering** is the process of using domain knowledge and mathematical transformations to create informative feature representations $\mathbf{X}' = g(\mathbf{X})$ that enhance model performance, expressiveness, and stability.

While linear models can only fit straight hyperplanes over raw inputs $x_1, x_2$, feature engineering transforms features into non-linear, interactive, or gaussianized spaces where linear separators succeed.

Scikit-learn provides two main categories of feature engineering tools:
1. **Feature Generation Transformers:** Construct new synthetic features from original ones (e.g., polynomial combinations $x_1 x_2, x_1^2$, non-linear power transforms $\log(x), \sqrt{x}$, quantile mapping, binning continuous ranges into discrete categories).
2. **Feature Selection Estimators:** Select a high-quality subset of $k$ features from a high-dimensional space $p \gg k$ based on variance, statistical tests ($\chi^2, F$-tests, Mutual Information), or model coefficients.

The key insight: Feature Engineering expands complex non-linear relationships into explicit columns, allowing simple models to capture high-order interactions while controlling feature dimensionality.

---

## 2. THE PROBLEM IT SOLVES

Suppose you have two continuous features $x_1$ (height) and $x_2$ (width) predicting land price $y$. The actual true pricing function depends on **Area** ($x_1 \cdot x_2$), a multiplicative non-linear interaction term.

A standard **Linear Regression** model over raw inputs attempts to fit:
$$\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2$$
Because the model lacks an explicit $x_1 x_2$ term, it cannot capture the multiplicative area effect, resulting in high underfitting error.

`PolynomialFeatures(degree=2, interaction_only=True)` solves this structural underfitting:
```python
# Automatically generates interaction column x1 * x2
poly = PolynomialFeatures(degree=2, interaction_only=True, include_bias=False)
X_poly = poly.fit_transform(X) # Contains [x1, x2, x1*x2]
```
The linear model can now fit $\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 (x_1 x_2)$, perfectly modeling the underlying multiplicative physics.

## 3. FORMAL DEFINITION & NOTATION

### 1. Polynomial Feature Combinatorics
For $p$ input features expanded to degree $d$, the total number of output features $M$ generated by `PolynomialFeatures` is given by the combination formula:

$$M = \binom{p + d}{d} = \frac{(p + d)!}{p! \, d!}$$

### 2. Yeo-Johnson Power Transformation
To stabilize variance and transform skewed data towards a Normal distribution $\mathcal{N}(0, 1)$, `PowerTransformer(method='yeo-johnson')` applies the parameterized transform $\psi(\lambda, x)$:

$$\psi(\lambda, x) = \begin{cases} 
\frac{(x + 1)^\lambda - 1}{\lambda} & \text{if } \lambda \neq 0, x \ge 0 \\ 
\ln(x + 1) & \text{if } \lambda = 0, x \ge 0 \\ 
-\frac{(-x + 1)^{2 - \lambda} - 1}{2 - \lambda} & \text{if } \lambda \neq 2, x < 0 \\ 
-\ln(-x + 1) & \text{if } \lambda = 2, x < 0 
\end{cases}$$

Where optimal $\lambda$ is estimated via Maximum Likelihood Estimation (MLE).

| Technique | Class Name | Input Dimensionality | Purpose |
|---|---|---|---|
| Polynomial Interaction | `PolynomialFeatures(degree=d)` | $p$ features | Generates products $x_i^a x_j^b$ up to degree $d$ |
| Quantile Mapping | `QuantileTransformer(output_distribution='normal')` | $p$ features | Maps arbitrary distributions to Gaussian |
| Feature Discretization | `KBinsDiscretizer(n_bins=k, encode='onehot')` | $p$ continuous features | Bins continuous data into $k$ discrete intervals |
| Univariate Selection | `SelectKBest(score_func=f_classif, k=10)` | $p$ features | Keeps $k$ highest scoring statistical features |
| Model-Based RFE | `RFE(estimator, n_features_to_select=5)` | $p$ features | Recursively drops least important features |

## 4. INTUITION & COMBINATORIAL EXPANSION

### Polynomial Feature Expansion Table

| Input Dimensionality ($p$) | Degree ($d$) | Generated Columns Formula | Total Output Features ($M$) |
|---|---|---|---|
| $p=2$ (`[x1, x2]`) | `d=2` | `[1, x1, x2, x1^2, x1*x2, x2^2]` | **6 features** |
| $p=5$ | `d=2` | $\binom{5+2}{2}$ | **21 features** |
| $p=10$ | `d=2` | $\binom{10+2}{2}$ | **66 features** |
| $p=20$ | `d=3` | $\binom{20+3}{3}$ | **1,771 features** *(Explosion!)* |

- **Combinatorial Explosion Risk:** High feature counts ($p > 20$) with $d \ge 3$ create extreme feature inflation, requiring `interaction_only=True` or downstream regularized feature selection (`SelectKBest`, `L1/Lasso`).

## 5. WORKED EXAMPLE 1: Simple Case

**Problem:**  
Given a single skewed column of data $X = [[1.0], [10.0], [100.0], [1000.0]]$, map it to a uniform distribution between $[0, 1]$ using `QuantileTransformer`.

**Step-by-Step Solution:**

```python
import numpy as np
from sklearn.preprocessing import QuantileTransformer

# 01. Define Skewed Data
X = np.array([[1.0], [10.0], [100.0], [1000.0]])

# 02. Instantiate QuantileTransformer
qt = QuantileTransformer(n_quantiles=4, output_distribution='uniform', random_state=42)

# 03. Fit and Transform
X_trans = qt.fit_transform(X)

print("Original Skewed Matrix:\n", X.ravel())
print("Transformed Uniform Matrix:\n", np.round(X_trans.ravel(), 4))
# Output: Transformed values are spread uniformly between 0.0 and 1.0!
# [0.0, 0.3333, 0.6667, 1.0]
```

## 6. WORKED EXAMPLE 2: Realistic Case

**Problem:**  
Construct a high-dimensional feature engineering pipeline that expands 10 input features using `PolynomialFeatures(degree=2)`, filters out zero-variance features using `VarianceThreshold`, and selects the top 5 most informative features for classification using `SelectKBest` with Mutual Information (`mutual_info_classif`).

```python
import numpy as np
import pandas as pd
from sklearn.datasets import make_classification
from sklearn.preprocessing import PolynomialFeatures
from sklearn.feature_selection import VarianceThreshold, SelectKBest, mutual_info_classif
from sklearn.pipeline import Pipeline
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split

# 1. Generate Synthetic Dataset (100 samples, 10 features)
X_raw, y = make_classification(n_samples=100, n_features=10, n_informative=4, random_state=42)

# Add a zero-variance constant feature
X_raw[:, 0] = 5.0

# 2. Build Feature Engineering & Selection Pipeline
fe_pipeline = Pipeline(steps=[
    # Step A: Expand features to polynomial degree 2 (66 features generated)
    ('poly', PolynomialFeatures(degree=2, include_bias=False)),
    
    # Step B: Remove constant/near-zero variance features
    ('variance_filter', VarianceThreshold(threshold=0.01)),
    
    # Step C: Select Top 5 features using Mutual Information
    ('select_k', SelectKBest(score_func=mutual_info_classif, k=5)),
    
    # Step D: Final Classifier
    ('clf', RandomForestClassifier(n_estimators=50, random_state=42))
])

# 3. Train Pipeline and Evaluate
X_train, X_test, y_train, y_test = train_test_split(X_raw, y, test_size=0.25, random_state=42)
fe_pipeline.fit(X_train, y_train)

score = fe_pipeline.score(X_test, y_test)
print(f"Pipeline Test Classification Accuracy: {score:.4f}")

# Inspect Selected Feature Mask
selected_mask = fe_pipeline.named_steps['select_k'].get_support()
print(f"Number of features selected: {np.sum(selected_mask)} out of expanded set.")
```

## 7. CORNER CASES & FAILURES

### 1. Polynomial Combinatorial Explosion
Expanding high-dimensional feature matrices (e.g., $p = 100$) to `degree=3` generates $\binom{103}{3} = 176,851$ columns, consuming gigabytes of RAM and causing severe overfitting.
```python
# Fix: Limit degree=2 and set interaction_only=True
poly = PolynomialFeatures(degree=2, interaction_only=True, include_bias=False)
```

### 2. Multicollinearity from Polynomial Terms
Generating powers $x_1, x_1^2, x_1^3$ introduces strong multicollinearity between columns, causing unstable coefficients in unregularized Linear Regression.
```python
# Fix: Pair PolynomialFeatures with Ridge/Lasso regularization or Standardize features first!
```
